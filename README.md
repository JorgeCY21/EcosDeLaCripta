# Ecos de la Cripta

Proyecto de videojuego 3D desarrollado en Unity. La Fase 1 incluye menú, instrucciones y un nivel de cinco criptas con enemigos, trampas, mejoras y un jefe final.

## Abrir el proyecto

1. Instala **Unity 6000.3.15f1** desde Unity Hub.
2. Añade esta carpeta como proyecto en Unity Hub.
3. Abre `Assets/Scenes/MainMenu.unity` y pulsa **Play**.

Para generar una versión de Windows de 64 bits, usa **Ecos de la Cripta > Crear ejecutable Windows** en el menú del Editor. El resultado se guarda en `Entregables/EcosDeLaCripta_Windows/`, una carpeta local excluida de Git.

## Controles

| Acción | Control |
| --- | --- |
| Moverse | WASD |
| Apuntar y disparar | Ratón y clic izquierdo |
| Saltar | Espacio |
| Impulso | Shift |
| Alternar vista cenital / primera persona | T |

El proyecto conserva los archivos `.meta` de Unity para mantener las referencias entre escenas, scripts y recursos. Las carpetas generadas como `Library` se crean automáticamente al abrirlo.
